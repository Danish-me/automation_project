# Automation Project:-

This project is a Python-based automation system that performs:

## Features:
- Reads Excel data
- Processes data
- Generates temperature graphs
- Creates reports
- Sends automated email notifications

## Technologies Used:
- Python
- Pandas
- Matplotlib

## Project Structure:
automation_project/
│
├── data/
├── src/
├── output/
├── main.py

## How to Run:
1. Install dependencies:
   pip install pandas matplotlib

2. Run:
   python main.py
